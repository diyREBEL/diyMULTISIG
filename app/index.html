DIY Multisig

Multisig-Wallet

Mehrere Schlüssel, eine Wallet. Zum Ausgeben müssen mehrere Signiergeräte zustimmen. Diese App hält keine privaten Schlüssel – sie baut nur Transaktionen und zeigt sie als QR-Code.

Die App speichert nichts. Lade deine Wallet bei jedem Start aus dem Backup.

Schlüssel hinzufügen

Exportiere auf jedem Signiergerät den Multisig-Schlüssel (Native SegWit) als QR-Code und scanne ihn.

So geht's am Gerät

SeedSigner: Seed laden → Seeds → deinen Seed wählen → Export Xpub → Multisig → Native Segwit → als Koordinator "Sparrow" wählen.

Jade: entsperren → Options → Wallet → Export Xpub → unten "Options": Wallet = Multisig, Script = Native Segwit.

Die App zeigt danach den Fingerabdruck an. Er muss mit dem Fingerabdruck auf dem Gerät übereinstimmen.

    Geräte registrieren und sichern

    1. Wallet-QR auf jedem Gerät scannen

    Damit kennt jedes Gerät die anderen Schlüssel und kann Empfangsadressen und Wechselgeld selbst prüfen.

    QR-Dichte
    So geht's am Gerät

    Jade: im Hauptmenü "Scan" wählen und den animierten Code scannen. Jade zeigt alle Schlüssel an – vergleiche die Fingerabdrücke und bestätige. Jade speichert die Wallet dauerhaft.

    SeedSigner: speichert nichts dauerhaft. Vor dem Signieren: Scan → diesen Wallet-QR scannen. Dann kann SeedSigner das Wechselgeld prüfen. Darum diesen QR-Code auch ausdrucken (Descriptor als QR).

    2. Backup erstellen – jetzt!

    Die App speichert nichts. Beim nächsten Start lädst du die Wallet aus diesem Backup. Drucke das Backup-Blatt aus (oder sichere es als PDF/Datei).

    Der Descriptor ist der Bauplan der Wallet. Ohne ihn können die Seeds allein das Geld nicht wiederfinden. Lege bei jedem Seed-Backup ein Exemplar dazu. Er enthält keine privaten Schlüssel, verrät aber dein Guthaben.

    Prüfsumme: – notiere sie. Die App zeigt sie auf der Übersicht an; weicht sie je ab, wurde die Wallet verändert.

    Wallet laden

    Füge den Descriptor oder die Setup-Datei ein, oder scanne einen QR-Code (z.B. Backup-Export einer Jade).

    Empfangen

    Adresse auf einem Gerät prüfen (empfohlen bei grossen Beträgen)

    Jade (Wallet registriert): Scan → den QR-Code oben scannen → Jade meldet "Address verified".

    SeedSigner: Scan → den QR-Code oben scannen → Multisig wählen. Ist der Wallet-QR noch nicht geladen, fragt SeedSigner danach.

    Nur so ist sicher, dass niemand die Adresse in dieser App ausgetauscht hat.
